# Social anomalies — user requirements
No real kick, ban, world removal, application exit, filesystem manipulation outside mod-owned data, or connection termination as a horror mechanic. Fake disconnect is an AlertScreen whose button dismisses it; never calls disconnect. Skip when another screen is open. Real server moderation is unaffected.
Fake join adds a synthetic UUID to the viewer's TAB using vanilla player-info packet, and emits vanilla join text. Fake leave removes the same UUID and emits vanilla leave text after 600 ticks. Names currently fictional, checked against online names case-insensitively. Real player rows and authenticated chat are not touched. One phantom per viewer, no actual player or connection. Cleanup on shutdown, death or name conflict. 
Essential 1.5.2 supports NeoForge 26.3 (official changelog). Future optional client-local provider: read only the consenting local player's available friend names through a supported API, no server collection, auth tokens, private messages, external lookup, friend requests or real social actions. Fallback to fictional identities. Skin/mimic and TAB should share one synthetic identity lifetime, never use a real user's UUID for fake entries. A fake departure of an actual online player needs a separate reversible presentation layer and restoration that respects genuine server list changes. This iteration does not implement that, actual friend integration, fake bans, or linked mimic appearance. Build and multiplayer behavior unverified.
