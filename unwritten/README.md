# The Unwritten
Target: Minecraft Java 26.3 / NeoForge / Java 25. Standalone original horror mod, not a modpack.
First milestone: independent per-player director, bounded tension and karma, randomized cooldowns and progression. Current policy emits abstract decisions only; game adapter, persistence, entity assets, multiplayer isolation and actual effects are not implemented yet.
Reference archive inventory: The God has CarmaEvent procedures, watcher/follower entities, sacrifice and dimension procedures. The Broken Script has fake-player mimic AI, block-break investigation, stalking conditions and maze navigation. These are inspiration, not copied code or resources.
Next: connect server tick and player actions, save per-player state, implement spatial sound and observer entity with visibility constraints, then fake presence and reversible local anomalies. Never modify real OS files or intentionally crash clients. Main modpack remains untouched.
