# EHTID Horror v14.2: диагностика и снижение 2 TPS + чистый экран

**Причина 2 TPS пока не доказана.** 2 TPS означает ~500 мс на серверный тик
(вместо бюджетных 50 мс при 20 TPS). FPS и TPS не одно и то же:
уменьшение графических настроек не обязано чинить TPS.

  400–1000 вместо 80–200, разрушение источников света в радиусе 12 вместо 32.

  вероятности, увеличен разрыв между disruptive events, реже появляются
  Silhouette, invisible watcher и villager insanity.
- Otherworld: intruderFrequency 1.2 -> 0.8, все актуальные intruder'ы сохранены.
- Sound of Fear: максимальное сканирование блоков 900 -> 160,
  радиус 14 -> 8, вертикальный радиус 5 -> 3,
  scheduler interval 20 -> 80 тиков.
- Опции по умолчанию: simulationDistance 8 -> 5,

## Как безопасно обновить
1. Сделать резервную копию папки мира (`saves/<название мира>`).
2. Обновить сборку, импортировав новый ZIP из GitHub Actions
   «Validate Horror Pack» -> artifact «EHTID-Horror-Checked»,
   либо создать новый профиль CurseForge из актуального manifest ZIP.
3. **Старые миры:** закрой игру; для уже существующих миров конфиги из
   `overrides/defaultconfigs/*.toml` обычно НЕ переписывают
   `saves/<мир>/serverconfig/*.toml`. Сохрани собственные правки,
   затем вручную обнови соответствующие параметры из
   `defaultconfigs` в `serverconfig` (или осторожно скопируй весь
   файл, если кастомных правок нет). НЕ удаляй весь `serverconfig`.
4. Если пользовательская `config/` уже существует, проверь, что новые
   `DisturbedConfig.toml`, `gothamterror-common.toml` и
   `psycho-common.toml` не были оставлены старыми лаунчером.
5. В уже созданных мирах старые сущности *не исчезнут* после изменения
   spawn rate. Не удаляй всех мобов командой /kill: это ломает прохождение.

## Сбор показателей
Открой лагающий мир и воспроизведи 2 TPS. Из чата с читами/оператором
запусти на интегрированном или выделенном Forge сервере:

```
/spark profiler start --timeout 90
```

Дождись 90 секунд реального времени и пришли ссылку spark.lucko.me из чата.
Если не появляется ссылка, используй `/spark profiler stop`.
Для графического *клиентского* потока Forge применяется `/sparkc`,
но для серверных 2 TPS нужен **серверный** `/spark`.

Дополнительно:
```
/spark tps
/spark health
```

Сохрани `logs/latest.log` и, по возможности, снимок F3 с видимыми
числами сущностей. Сообщи: мир новый или старый, одиночный или Essential,
сколько игроков, TPS сразу при запуске или после события/исследования.
При неработающей команде spark включи команды в одиночном мире через
«Открыть для сети -> Использование читов: ВКЛ» либо выдай op на сервере.

## Интерпретация
- Основное время в `ServerLevel.tickEntities` / `Mob.tick` / pathfinding:
  подозрение на массу существ и тяжёлый AI конкретного хоррор-мода.
- Большое время в `MinecraftServer.tickChildren` / chunk generation:
  исследование мира/генерация структур может быть важнее спавна.
- Зависания в модовых методах — определить мод по stacktrace из spark,
  после чего адресно править именно его.
- Если новый мир 20 TPS, а старый 2 TPS, проблема может быть в накопленных
  сущностях/чанках, а не в наборе модов.
